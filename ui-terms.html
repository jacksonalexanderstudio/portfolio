01

Layout

The bones of a page: regions, columns, edges, and how they hold when the width changes.

Viewport

“In web browser terms, it refers to the part of the document being viewed in the browser window (or on-screen, if the document is being viewed on a mobile browser or a desktop browser in full-screen mode).”

also: window, screen

Container

The type area of the page: in Müller-Brockmann’s system, the field inside the margins that carries text and image. On screen, a centred column held to a maximum width so that measure and grid keep their proportions on wide displays.

also: wrapper, content column, max-width

Page margin

The unprinted space between the type area and the edge of the format. Müller-Brockmann and Bringhurst treat the margins as proportions of the page rather than leftovers: the margins fix the type area, and the type area fixes the columns.

also: outer margin, side gutter

Column grid

A system of vertical fields and gutters dividing the type area, to which every element on the page is aligned. Müller-Brockmann builds the grid from the leading of the body type, so that every field is a whole number of lines. “Like tables, grid layout enables an author to align elements into columns and rows.”

also: 12-column grid, grid system, columns

Gutter

“Gutters or alleys are spacing between content tracks.”

also: column gap

Span

“A grid column is a vertical track in a CSS grid layout, and is the space between two vertical grid lines.” A span is the number of such tracks an item occupies.

also: column span

Row

“A grid row is a horizontal track in a CSS grid layout, that is the space between two horizontal grid lines.”

also: band

Section

“The

HTML element represents a generic standalone section of a document, which doesn't have a more specific semantic element to represent it. Sections should always have a heading, with very few exceptions.”

also: band, block, strip

Hero

Nielsen Norman Group’s name for the large image or banner placed at the top of a page as the first thing a visitor sees, usually carrying the page’s main message.

also: opener, lead

Header

“The

HTML element represents introductory content, typically a group of introductory or navigational aids. It may contain some heading elements but also a logo, a search form, an author name, and other elements.”

also: masthead, top bar, site header

Nav

“The

HTML element represents a section of a page whose purpose is to provide navigation links, either within the current document or to other documents. Common examples of navigation sections are menus, tables of contents, and indexes.”

also: navigation, menu

Sidebar

“This example uses

to mark up a paragraph in an article.” The sidebar is the column beside the main content that carries navigation, an index, or related material.

also: rail, side column

Footer

“The

HTML element represents a footer for its nearest ancestor sectioning content or sectioning root element. A
typically contains information about the author of the section, copyright data or links to related documents.”

also: page foot

Aside

“The

HTML element represents a portion of a document whose content is only indirectly related to the document's main content.”

also: sidenote, marginal note, callout

Fold

Nielsen’s term, borrowed from the newspaper fold, for the bottom edge of the first screen: what sits above it is seen without scrolling, and his eyetracking studies found that readers spend most of their viewing time there.

also: above the fold, below the fold

Full-bleed

Bleed: a printed image that runs past the trim edge of the page so that no margin shows after cutting. On screen, an element that runs to the viewport edges, ignoring the container.

also: edge-to-edge, bleed

Inset

Positioned inward from its parent’s edges by a fixed distance on every side.

also: set in, indented

Offset

Moved from its natural grid position by a deliberate distance, usually to break alignment on purpose.

also: shifted, nudged, staggered

Overlap

“The z-index CSS property sets the z-order of a positioned element and its descendants or flex and grid items. Overlapping elements with a larger z-index cover those with a smaller one.”

also: layering, stacking, z-order

Sticky

“The element is positioned according to the normal flow of the document, and then offset relative to its nearest scrolling ancestor and containing block (nearest block-level ancestor), including table-related elements, based on the values of top, right, bottom, and left.”

also: pinned on scroll

Fixed

“The element is removed from the normal document flow, and no space is created for the element in the page layout. The element is positioned relative to its initial containing block, which is the viewport in the case of visual media.”

also: pinned, locked

Stack

Items placed one under another in a single column with a set gap. The default when a row wraps at phone width.

also: vertical stack, stacked

Split

Two or more panes sharing a row. A 60/40 split leans one side; two-up and three-up name the count.

also: two-up, 50/50, side by side

Aspect ratio

“The aspect-ratio CSS property allows you to define the desired width-to-height ratio of an element's box.” Common ratios: 1:1, 3:2, 16:9, 4:5.

also: proportion, ratio

Breakpoint

“The points at which a media query is introduced, and the layout changes, are known as breakpoints.”

also: media query

Fluid

“The term responsive design, coined by Ethan Marcotte in 2010, described using fluid grids, fluid images, and media queries to create responsive content.”

also: responsive, elastic

Masonry

“Grid lanes layout is a layout method where one axis uses a strict grid layout and the other uses a stacking algorithm. Each item is placed into the lane with the most available space, producing a tightly packed layout without strict tracks on the stacking axis.”

also: Pinterest grid

02

Space

Distances, rhythms, and the grids that make them regular.

Padding

“An element's padding area is the space between its content and its border.”

also: inner spacing, inset spacing

Margin

“Margin box: The margin is the outermost layer, wrapping the content, padding, and border as whitespace between this box and other elements; size it using margin and related properties.” “The top and bottom margins of blocks are sometimes combined (collapsed) into a single margin whose size is the largest of the individual margins (or just one of them, if they are equal), a behavior known as margin collapsing.”

also: outer spacing

Gap

“The gap CSS shorthand property sets the gaps (also called gutters) between rows and columns on multi-column, flex, and grid containers.”

also: grid gap, spacing between items

Whitespace

The unprinted area of the composition. In Müller-Brockmann’s grid systems empty space is an active element of the design with the same standing as type and image, not what remains after they are placed.

also: negative space, empty space, air

Baseline grid

In Müller-Brockmann’s method the leading of the body text sets a horizontal grid across the whole type area. Every line of every column sits on it, so lines register across columns and every field of the grid is a whole number of lines tall.

also: 4px grid, 8px grid, vertical grid

Spacing scale

Material Design’s spacing method: every measurement is taken from an 8 dp grid, with a 4 dp grid for small elements, so that spacing is chosen from a fixed set rather than case by case.

also: spacing tokens, space system

Modular scale

“A modular scale is a sequence of numbers that relate to one another in a meaningful way.”

also: type scale, ratio

Vertical rhythm

Rutter: “vertical rhythm – the spacing and arrangement of text as the reader descends the page – is contributed to by three factors: font size, line height and margin or padding.” Bringhurst: “Space in typography is like time in music.”

also: rhythm

Optical centering

Arnheim’s observation that the perceptual centre of a field lies above its geometric centre: an element placed at the mathematical middle reads as sitting low.

also: optical vs mathematical

Density

Material Design’s term for how much content a component fits into a given area; higher density fits more, lower density gives more room.

also: tight, loose, airy

Registration

Register: in printing, the exact alignment of successive impressions or colours with one another. In layout, elements sharing a common edge.

also: alignment edge, shared edge

Hang

Bringhurst’s hanging indent and hanging punctuation: setting a first line, a bullet, or a quotation mark past the left margin so that the text block itself keeps a clean edge.

also: outdent, hanging

Breathing room

Spacing generous enough that elements read as separate objects at rest. In this studio the floors are 16px gaps, 18 to 24px card padding, and 36px above section heads.

also: air, room

Proximity

The Gestalt law of proximity (Wertheimer, 1923): elements close to one another are perceived as a group. Robin Williams’s first principle of design: group related items together.

also: grouping

03

Type

Letters, lines, and the measurements between them.

Typeface vs font

Lupton draws the line: a typeface is the design of the letterforms; a font is the software (or once, the metal) that delivers it. In CSS, font-family names the typeface.

also: family, face, cut

Weight

“The font-weight CSS property sets the weight (or boldness) of the font. The weights available depend on the font-family that is currently set.” The CSS scale runs 100 to 900; 400 is normal, 700 is bold.

also: thin, light, regular

Size

“The font-size CSS property sets the size of the font.” In Bringhurst’s terms the size is the body of the type, the em, not the height of any letter.

also: point size, px

Leading

“In typography, leading is an amount of space included above and below text to provide spacing between lines. Historically, in physical typesetting, pieces of actual lead were used to implement this spacing, which is where the name comes from.”

also: line-height, line spacing

Tracking

“The letter-spacing CSS property sets the spacing between text characters. This value is added to the natural spacing between characters while rendering the text.”

also: letter-spacing

Kerning

“Kerning affects how letters are spaced. In well-kerned fonts, this feature makes character spacing more uniform and pleasant to read by reducing white space between certain character combinations.”

also: pair spacing

Measure

Bringhurst’s guidance: 45 to 75 characters per line is satisfactory for a single column of text; 66 characters, counting letters and spaces, is widely regarded as ideal.

also: line length, column width

Baseline

“A baseline is an imaginary line along the inline axis of a line box along which individual glyphs of text are aligned.”

also: base line

x-height / cap height

In Bringhurst’s glossary the x-height is the height of the lowercase letters without ascenders or descenders, taken from the x; the cap height is the height of the capitals.

also: x-height, cap height

Ascender / descender

Bringhurst: ascenders are the strokes of lowercase letters that rise above the x-height (b, d, k); descenders are the strokes that fall below the baseline (g, p, y).

also: ascender, descender

Case

“The text-transform CSS property specifies how to capitalize an element's text. It can be used to make text appear in all-uppercase or all-lowercase, or with each word capitalized.”

also: uppercase, lowercase, sentence case

Alignment

“The text-align CSS property sets the horizontal alignment of the inline-level content inside a block element or table-cell box.” Bringhurst prefers flush left with a ragged right for continuous text.

also: flush left, ragged right, centered

Rag

The uneven right-hand edge of unjustified text. Bringhurst asks for a rag that is soft and unpatterned: no shapes, steps, or holes.

also: ragged edge

Widow / orphan

“In typography, an orphan is the first line of a paragraph that appears alone at the bottom of a page.” “In typography, a widow is the last line of a paragraph that appears alone at the top of a page.”

also: widow, orphan

Hierarchy

Lupton: typographic hierarchy expresses the organisation of content, emphasising some elements and subordinating others, through size, weight, placement, and space.

also: type scale, levels

Display vs text

“The font-optical-sizing CSS property sets whether text rendering is optimized for viewing at different sizes.” Bringhurst: display sizes want tighter fit and finer detail; text sizes want sturdier strokes and open spacing.

also: headline face, reading face, optical size

Eyebrow

Harrower: in newspaper make-up a kicker is a short line set above the main headline. On the web the same device is called an eyebrow or overline.

also: kicker, overline, superhead

see

Dek

Harrower: a deck is a smaller headline set below the main headline, expanding it in a sentence.

also: subhead, standfirst, deck

Rule

A rule is a printed line. A hairline is the finest rule a process will render.

also: hairline, divider, separator

Indent

“The text-indent CSS property sets the length of empty space (indentation) that is put before lines of text in a block.”

also: first-line indent, hanging indent, outdent

Figures

“The font-variant-numeric CSS property controls the usage of alternate glyphs for numbers, fractions, and ordinal markers.” Bringhurst’s terms: lining figures stand on the baseline at cap height; text (old-style) figures rise and fall like lowercase; tabular figures share one width, proportional figures do not.

also: numerals, lining, oldstyle

Optical alignment

“The hanging-punctuation CSS property specifies whether a punctuation mark should hang at the start or end of a line of text. Hanging punctuation may be placed outside the line box.”

also: hanging punctuation, optical margin

Classification

Vox’s 1954 system, adopted by ATypI, groups typefaces by historical form: humanist, garalde, transitional, and didone serifs; mechanistic (slab) serifs; and the lineals, the sans serifs, divided into grotesque, neo-grotesque, geometric, and humanist.

also: grotesk, geometric, humanist

Drop cap / pull quote

“The initial-letter CSS property sets the size and sink for dropped, raised, and sunken initial letters.” Harrower: a pull quote is a line lifted from the story and set in larger type to draw the reader in.

also: drop cap, pull quote, initial

Running head / folio

Bringhurst’s glossary: the running head is the line at the head of each page repeating the title or chapter; the folio is the page number.

also: running head, folio, page furniture

Hyphenation

“The hyphens CSS property specifies how words should be hyphenated when text wraps across multiple lines.”

also: hyphens, word break

04

Color

Hue, value, contrast, and the layers that carry them.

Hue

The color’s position on the wheel: red, orange, blue. Two colors can share a hue at different saturation and lightness.

also: color family

Saturation

How far a color sits from grey at the same lightness. Full saturation is vivid; zero is grey.

also: chroma, vividness, intensity

Lightness

How light or dark a color is, independent of hue. What black-and-white photography preserves.

also: value, tone, luminance

Tint / shade / tone

A tint adds white to a hue, a shade adds black, a tone adds grey. Tints of the stone make the figure grounds here.

also: tint, shade, tone

Accent

The single color used sparingly against the neutrals to mark emphasis, links and active states. Here it is warm stone, #8C8880.

also: highlight color, brand color

Neutral

A low-saturation color used for grounds and text. A neutral with a slight hue bias reads as chosen; a pure grey reads as default.

also: grey, warm grey, cool grey

Foreground / background

Foreground is what is drawn (text, marks); background is what it is drawn on. Contrast is measured between the two.

also: fg/bg, ground, text color

Surface

The background of a distinct layer: page, card, sheet. Each surface can take its own tint to separate it from the one below.

also: layer ground, panel background

Contrast

The luminance difference between foreground and background, written as a ratio. 4.5:1 is the floor for body text; 3:1 for large text.

also: contrast ratio

Opacity

How much of what lies beneath shows through, 0 (invisible) to 1 (solid). A translucent layer takes on the color behind it.

also: alpha, transparency, translucent

Muted

Lowered in saturation or contrast so it reads as secondary. The stone-70 captions here are muted ink.

also: knocked back, desaturated, subdued

Warm / cool

Warm colors lean toward red and yellow, cool toward blue. Neutrals lean too: this stone is warm.

also: warm, cool, temperature

Monochrome

One hue in several lightnesses, or no hue at all. The figures in this index are monochrome.

also: single hue, greyscale, black and white

Duotone

An image remapped to two colors: one for shadows, one for highlights. A print process before it was a filter.

also: two-color

Gradient

A continuous transition between two or more colors across a distance or angle. Reads as generic when decorative; useful as a scrim.

also: fade, ramp, blend

Overlay / scrim

A translucent layer laid over an image so text on it stays legible. A scrim is a gradient overlay that fades to nothing.

also: wash, tint layer, scrim

Inverted

Foreground and background swapped: light text on a dark ground. Dark mode inverts the whole page; a knockout inverts one element.

also: dark mode, reversed out, knockout type

Token

A named value used everywhere it applies: --accent rather than #8C8880 typed thirty times. Change the token, change the site.

also: variable, CSS variable, design token

see

Swatch / palette

A swatch is one color sample; a palette is the chosen set. Four to six values is a working palette.

also: swatch, palette, color set

Border

A line along an element’s edge. Stroke is the same idea on a drawn shape; an outline sits outside the box and is used for focus.

also: stroke, outline, keyline

Shadow

A soft dark shape beneath an element implying it floats. Elevation systems step the shadow with height. Absent in a flat design.

also: drop shadow, elevation

Grain / noise / texture

Fine random variation laid over a flat area so it reads as material rather than pixel. Film grain, paper tooth, halftone.

also: grain, noise, texture

05

Image

Framing, fitting, and the treatments an image can take.

Crop

Cutting an image to a new frame. Changes the composition, not the pixels within it.

also: trim, reframe

Cover vs contain

Two ways to fit an image in a box of a different ratio. Cover fills the box and crops the overflow; contain shows the whole image and leaves space.

also: fit, object-fit, fill the box

Letterbox / pillarbox

The bands left when an image is contained in a box of another ratio: letterbox above and below (wide image, tall box), pillarbox at the sides.

also: letterbox, pillarbox, bars

Bounding box

The rectangle an image is placed in. When the image does not fill it, the box shows through. In this studio the box is never a visible grey.

also: image box, container box

Focal point

The point of the image kept in view when it crops. Set as a position: center, or 30% 20%.

also: object-position, anchor point

Retina / 2x

Screens with two or more device pixels per CSS pixel. Images need twice the pixel width to stay sharp.

also: DPR, srcset, high-density

Lazy load

Loading an image only when it nears the viewport. Cuts initial page weight.

also: deferred loading

Placeholder / blur-up

A tiny blurred version shown until the full image arrives, so the layout never jumps.

also: LQIP, low-res preview, blur-up

Poster frame

The still shown in a video’s place before it plays. On an autoplay loop, the first frame.

also: poster, still frame

Autoplay / loop / muted / inline

Video attributes. Autoplay starts without a press (allowed only when muted); loop repeats; playsinline keeps it in place on iOS.

also: autoplay, loop, muted

Knockout / alpha

An image with a transparent background so the ground shows through. PNG and WebP carry alpha; JPG cannot.

also: transparent background, cut out, matte

Halftone / dither

Simulating tone with dots (halftone) or scattered pixels (dither). Print and early-screen textures.

also: halftone, dither, dot screen

Vignette

Darkening or lightening toward the edges of an image.

also: edge darkening

Alt text

The text a screen reader speaks in place of an image. Describes what the image shows, not that it is an image.

also: alt, image description

Vector / raster

Vector describes shapes mathematically and scales without loss (SVG); raster stores pixels (PNG, JPG, WebP). Marks and diagrams are vector; photographs are raster.

also: SVG, PNG, JPG

Still

A single frame from a video, or any non-moving image.

also: frame, static image

06

Components

Named parts of an interface: what each is, and what its neighbours are.

Button

A control that performs an action on press. Solid (filled) for the primary action, ghost (outlined) for secondary, text (no box) for tertiary.

also: solid button, ghost button, text button

Link

Text that navigates elsewhere on press. Underlined by convention; the underline is the affordance.

also: text link, inline link, anchor

Pill / chip / tag / badge

Small labelled shapes. A pill is the rounded form; a chip is a selectable or removable pill; a tag labels a category; a badge shows a count or status on another element.

also: pill, chip, tag

Label

The short text naming a control or a value. Sits above or beside its field.

also: field label

Field

A box that accepts typed text. A textarea accepts several lines.

also: input, text field, textarea

Select

A control that opens a list to choose one value. A combobox also accepts typing to filter the list.

also: dropdown, menu, combobox

Toggle / checkbox / radio

A toggle switches one setting on or off at once; a checkbox marks any number of options; radios choose exactly one of a set.

also: toggle, switch, checkbox

Slider / stepper

A slider sets a value by dragging along a track; a stepper changes it in fixed increments with + and −. A knob is a slider that rotates.

also: slider, range, fader

Segmented control / tabs

A row of mutually exclusive options. A segmented control switches a view or setting inline; tabs switch between panels of content.

also: segmented control, tabs, tab bar

Accordion

A heading that opens to reveal its content and closes to hide it. Several stacked make an accordion.

also: disclosure, expandable, collapsible

Card / tile

A card is a bounded unit holding related content: image, title, text. A tile is a card in a grid, often image only.

also: card, tile

List / table

A list stacks items of one kind; a table arranges records in rows and columns with headers. A ledger is a table with a running total.

also: list, table, ledger

Modal / dialog

A layer over the page that takes focus and blocks the page until dismissed. A dialog asks a question; a modal is any blocking layer.

also: modal, dialog, popup

Sheet / drawer / panel

A layer that slides in from an edge: a sheet from the bottom on phones, a drawer from the side. A panel is the same thing docked open.

also: sheet, drawer, panel

Popover / tooltip

A small layer anchored to an element. A tooltip shows on hover and holds only text; a popover opens on press and can hold controls.

also: popover, tooltip, hover card

Toast / snackbar / banner

Brief messages. A toast appears and dismisses itself; a snackbar is a toast with one action; a banner stays until closed, across the top.

also: toast, snackbar, banner

Breadcrumb / pagination

A breadcrumb shows the path to the current page (Work / Studies / 01); pagination moves between numbered pages of results.

also: breadcrumb, pagination, page numbers

Progress / spinner / skeleton

A progress bar shows how much is done; a spinner shows that something is happening without saying how much; a skeleton shows the shape of content before it arrives.

also: progress bar, spinner, skeleton

Icon / glyph

A small pictorial symbol standing for an action or object. A glyph is any single drawn character, including icons and letters.

also: icon, glyph, pictogram

Mark / wordmark / lockup

A mark is the symbol alone; a wordmark or logotype is the name set in type; a lockup is the fixed arrangement of mark and name together.

also: mark, wordmark, logotype

Avatar / thumbnail

An avatar is a small image standing for a person or account; a thumbnail is a small preview of a larger image or page.

also: avatar, thumbnail, thumb

Carousel

A row of items scrolled or paged horizontally, one or more in view at once.

also: content slider, slideshow

Lightbox

A modal that shows an image or video large over a dimmed page, with next and previous.

also: image viewer

Marquee / ticker

Text that scrolls continuously across a line. A ticker feeds new items; a marquee loops the same ones.

also: marquee, ticker, scrolling text

Caption / footnote

A caption sits directly under an image or figure and describes it; a footnote is a reference set at the foot of the page or column.

also: caption, footnote

Index / table of contents

An index lists entries with their locations; a table of contents lists sections in order; an anchor link jumps to a place on the same page.

also: index, TOC, table of contents

Form

A group of fields with one submit action.

also: form

07

States

What a control looks like at rest and under the hand, and how pointing and scrolling behave.

Rest

How a control looks with nothing happening to it. Every other state is a change from this one.

also: default state, idle

Hover

The pointer is over the element but has not pressed. Touch screens have no hover; anything shown only on hover needs another way in.

also: rollover, mouseover

Focus

The element that will receive the next keypress. Shown with a ring or outline; never removed without a replacement.

also: focus ring, keyboard focus

Active

The moment of press, before release. Usually a darker fill or a slight scale down.

also: pressed, down

Selected

A persistent state after a choice: the current tab, the checked box, the active nav item.

also: checked, on, current

Disabled

Present but not operable. Lower contrast and no pointer response.

also: greyed out, inactive

Loading

The interface is waiting on something. Shown with a spinner, a skeleton, or a progress bar.

also: pending, busy

Empty state

What a view shows when it has nothing to list yet. States what belongs here and how to add it; never blank.

also: zero state, blank slate

Error / success / warning

Feedback states with their own colors, separate from the accent: what failed and how to fix it, what worked, what to check.

also: validation, semantic state, feedback state

Expanded / collapsed

Whether a disclosure shows its content. The control remains either way.

also: open, closed, toggled

Affordance

The visual cue that something can be acted on: an underline means link, a raised shape means press, a handle means drag.

also: cue, signifier

Hit area

The region that responds to a press, often larger than the visible shape. 44px is the floor on touch.

also: target, tap target, clickable area

Cursor

The pointer’s shape, which announces what a press will do: pointer (hand) for links, grab for draggable, text (I-beam) for selectable.

also: pointer, hand, grab

Tap / drag / swipe / scrub

Pointer gestures. Tap and click are a press and release; long-press holds; drag moves with the pointer held; swipe is a fast directional drag; scrub drags along a track to set a position.

also: tap, click, long-press

Scroll snap

The scroll position settles on defined points: each slide, each section.

also: snap points

Scroll-driven

Animation whose progress is tied to scroll position: scroll back and it reverses.

also: scrubbed by scroll, scroll-linked

Scroll-triggered

Animation that fires once when the element enters the viewport, then rests.

also: reveal on scroll, fade in on enter

Parallax

Layers moving at different speeds on scroll to suggest depth.

also: depth scroll

Scroll-jacking

Replacing the browser’s native scroll with scripted movement. Reads as loss of control.

also: hijacked scroll

Momentum

Scrolling or dragging that continues after release and decelerates. Native on touch.

also: inertia, fling

Debounce / throttle

Limiting how often something runs while input continues. Debounce waits for a pause; throttle allows one per interval.

also: debounce, throttle, rate limit

Persist

State that survives a reload: a chosen tab, a filter, a draft. Kept in the browser or on a server.

also: remember, saved state

08

Motion

Time, curves, and the choreography of change.

Transition

The change from one state to another, animated over a duration: a hover color, an opening drawer. Two endpoints and a curve.

also: state change

Animation

Movement described by keyframes over time, independent of state. Can loop.

also: keyframes, motion

Duration

How long a motion takes. 150 to 250ms for small changes, 300 to 500 for layout, longer only for ambient loops.

also: length, timing

Delay

The wait before a motion begins. Used for staggers and holds.

also: wait, offset in time

Easing

The rate of change across a duration. Ease-out starts fast and settles (entrances); ease-in starts slow and leaves fast (exits); ease-in-out does both; linear is constant, for loops only.

also: timing function, curve, ease-in

Spring

Motion modelled on a physical spring: it overshoots the target and settles. Damping sets how fast it settles; low damping bounces.

also: overshoot, bounce, damping

Stagger

The same motion applied to a sequence of elements with a small delay between each, so they arrive in order.

also: cascade, sequence

Keyframe

A defined state at a point in an animation; the browser fills the frames between.

also: key, pose

Loop

An animation that starts again when it ends. A plain loop jumps back to the start; see ping-pong for the seamless form.

also: repeat, infinite, cycle

Ping-pong

A loop that plays forward then backward, so the end meets the start without a jump. A palindrome loop holds at the end before reversing.

also: alternate, palindrome loop, reverse

Hold

A stretch of time in which nothing moves, inside a longer sequence. Gives the eye time to read the state.

also: dwell, pause, settle

Fade

A change of opacity. A fade-in arrives from transparent; a crossfade fades one thing out while another fades in.

also: crossfade, dissolve, opacity transition

Slide

Movement along a line, usually from just outside its resting place. Written as a translate.

also: translate, move in

Scale

A change of size from a transform origin. Scale from the center for emphasis; from an edge for a reveal.

also: zoom, grow, shrink

Wipe / mask / clip

Showing an element progressively by moving the edge of what is visible, while the element itself stays still.

also: wipe, mask, clip-path

Draw-on

A line that appears as if being drawn from one end to the other, by animating the dash of the stroke.

also: trace, stroke reveal, line animation

Morph

One shape becoming another through interpolated points.

also: shape tween

Cut

An instant change with no motion. The right choice more often than it is chosen.

also: no transition, hard change, instant

Ambient

Slow continuous motion that runs without input: a drifting field, a breathing mark. Sets a mood; never demands attention.

also: idle animation, background motion, ambient loop

Frame rate

How many frames per second the motion renders. 60 is smooth; drops read as jank. Animate transform and opacity to stay smooth.

also: 60fps, jank, stutter

Reduced motion

A system setting asking interfaces to minimise movement. Motion needs a static fallback.

also: prefers-reduced-motion

Scroll

Scroll-driven choreography: triggers, pins, scrubs, timelines, beats, and holds.

Trigger

The scroll positions at which a scroll animation begins and ends, each defined as a point on the element meeting a point in the viewport: “top of the element hits 80% of the viewport.”

also: scroll trigger, start, end

see

Markers

On-screen lines showing where each trigger starts and ends while building. Off in production.

also: debug markers, start and end lines

Pin

Holding an element fixed in the viewport for a set scroll distance while its animation plays, then releasing it. The pinned distance adds to the page height.

also: pinned section, pinned scene, pin distance

see

Scrub

Linking animation progress directly to scroll position, so scrolling back reverses it. A scrub value adds lag (0.6 s) so progress eases toward the scroll position instead of snapping to it.

also: scrubbed, scroll-scrubbed, tied to scroll

see

Progress

Where a scroll animation is between its start (0) and its end (1). Everything else can be driven from it: a curtain opening, a numeral counting, a color snapping.

also: progress value, 0 to 1, normalized progress

Timeline

A container that sequences tweens in time, each placed relative to the others or to labels. One timeline can be scrubbed, paused or reversed as a unit.

also: sequence, master timeline

Tween

One animation of one or more properties from a start value to an end value over a duration with an ease. Timelines are made of tweens.

also: tween, from / to, fromTo

see

Label / position

Named points on a timeline that tweens can start from; a position parameter places a tween relative to the previous one: “<” with it, “+=0.2” after it, “-=0.1” overlapping it.

also: label, position parameter, offset

Beat

A named moment in a sequence that other movements key to: the numeral snaps orange on the second-word beat. A choreography term, not a code one.

also: beat, hit, moment

Dead-hold

A stretch of pinned scroll where nothing animates, so the finished state can be read before release. Usually the last 20 to 40% of a pin.

also: hold, freeze, tail hold

see

Lead-in

The quiet time before the first movement, so the eye settles on the ground before anything arrives.

also: lead, quiet start, pre-roll

Release

The moment a pinned element returns to the flow and scrolls away. Anything still mid-motion at release reads as broken.

also: unpin, let go, release point

Toggle actions

What a triggered animation does on the four events: enter, leave, enter back, leave back. “Play, none, none, none” plays once and stays; “play, reverse, play, reverse” mirrors the scroll.

also: toggleActions, play once, reverse on leave

Refresh

Recomputing every trigger’s start and end after the layout changes: fonts loading, images arriving, a resize. Without it, positions were measured against the wrong page.

also: recalculate, recalc, lateRefresh

Scroll velocity

How fast the page is moving, used to drive effects that answer scrolling energy: skew, blur, marquee speed. Clamp it or it explodes on a flick.

also: velocity, scroll speed, skew on scroll

see

Smooth scroll

Replacing the browser’s stepped wheel scrolling with an interpolated, eased position. Adds feel; can break native behaviour, anchors and accessibility.

also: smooth scrolling, Lenis, inertia scroll library

see

Stacked cards

Successive sections that pin at the same viewport position so each new one covers the last, like cards dealt onto a pile.

also: card stack, stacking sections, pile on scroll

Horizontal section

A pinned section whose content translates horizontally as the page scrolls vertically.

also: horizontal scroll, sideways section, horizontal pin

Progress indicator

A bar or numeral showing how far through the page or chapter the reader is, driven from scroll progress.

also: progress bar, reading bar, scroll progress

In view

Knowing whether an element is in the viewport and by how much (threshold), with the viewport edges shifted by a margin. The standard trigger without a library. A hidden pane keeps observers from firing.

also: IntersectionObserver, intersection, threshold

Compositing

Animating only transform and opacity so the browser composites on the GPU without relayout. will-change hints a layer; too many layers cost memory.

also: GPU layer, transform-only, will-change

see

Pin spacing

The blank space added below a pinned element equal to its pin distance, so the page height accounts for the hold. Can be turned off when the next section should slide over.

also: pin spacer, spacer, extra height

Curtain

A masked image band that opens (unfurls) to a set height during a pin and closes again before release: a stage-curtain reveal keyed to progress.

also: stage curtain, unfurl, well

Choreography

The plan of what moves when: order, overlap, beats, holds. Written before code, as a timeline in words. The animation equivalent of a spec.

also: orchestration, sequence design, motion plan

see

Overlap

Starting the next movement before the last one ends, so the sequence feels continuous rather than stepped.

also: overlapping tweens, negative offset, crossing motion

see

Settle

The final approach of an element to its resting state, usually an ease-out or a damped spring. Everything should settle before the hold.

also: come to rest, land, resting state

Type effects

Typography in motion and text as surface: how letters arrive, move, and take treatments beyond a plain fill.

Split text

Breaking a text node into spans per character, word or line so each can animate separately. Lines must be re-split when the width changes. Choose the grain: characters for a few words, words for a line, lines for a paragraph.

also: split, chars, words

see

Telescoping title

A title that arrives by scaling from a much larger size down to its resting size (or the reverse), as in Saul Bass title sequences.

also: telescope, scale-in title, Saul Bass title

Typewriter

Characters appearing one at a time as if typed, usually with a caret. Reads as retro-terminal; use sparingly.

also: typing effect, character by character, type-on

Scramble

Characters cycling through random glyphs before settling on the real ones.

also: decode, shuffle, glitch text

Mask reveal

Each line rises from behind an invisible mask (a wrapper with overflow hidden) so it appears to emerge from its own baseline.

also: line mask, clip reveal, rise from the baseline

see

Counter

A numeral that counts from a start to its final value, or rolls digit by digit like an odometer.

also: count-up, rolling number, odometer

Kinetic type

Type whose movement carries meaning: weight, position and size changing in time. The broad category; the other text terms here are its species.

also: kinetic typography, moving type, animated type

Axis animation

Animating a variable font’s axes (weight, width, slant) continuously. Smooth and cheap compared with swapping fonts.

also: variable font animation, weight animation, width axis

Link motion

The small text motions on links: an underline that draws in from one side, a duplicate line that slides up to replace the first, a weight nudge.

also: underline draw, text swap, hover reveal

see

Caret

The blinking insertion bar used in typewriter effects. Blinks at about 500 ms.

also: blinking caret, text cursor

see

Tracking animation

Animating letter-spacing, usually from wide to normal on entrance, so the word appears to gather itself. Cheap and elegant; overused on hero titles.

also: letter-spacing tween, tracking in, expand and contract

Fade-up

Each word or line fades in while moving up a short distance. The default entrance for text; the mask reveal is its sharper cousin.

also: rise in, fade and rise, word-by-word

see

Blur-in

Text arriving from a blur to sharp with no movement. Reads as a lens focusing; keep it under a second and never on body text.

also: focus in, unblur, defocus

Outline text

Letters drawn as an outline with no fill. The stroke weight replaces the weight of the face; thin strokes break up at small sizes.

also: hollow text, stroked type, text-stroke

Knockout text

Letters cut out of a solid shape so whatever is behind shows through them. The shape carries the color; the type is a hole.

also: cutout text, punched out, text as a window

see

Image-filled text

Letters filled with an image or gradient via background-clip: text. If the background moves, the fill moves inside the letters.

also: background-clip text, image in the letters, gradient text

Fill wipe

A second color sweeping across the text, letter by letter or as a gradient position moving through it. A single pass reads as an accent; a loop reads as a loader.

also: color sweep, fill sweep, light through the letters

Highlighter

A colored band behind a phrase, growing in from the left like a marker stroke. Sits behind the text; the text stays ink.

also: marker highlight, highlight sweep, band behind text

Strikethrough draw

A line drawing through text to cancel it. Animated, it reads as a decision being made.

also: cross out, line-through animated, cancel

Text shadow

Copies of the text offset behind it: soft (shadow), stepped (long shadow), or many steps (extrusion). A depth cue; absent from a flat register.

also: drop shadow on text, long shadow, extruded type

Glitch

The text briefly misregisters: channel copies offset, horizontal slices shift, then it snaps back. One short hit reads as arrival; a loop reads as a gimmick.

also: RGB split, misregistration, displacement

Wave

Each character offset vertically by a sine, phase-shifted by its index, so the word ripples from one end to the other.

also: ripple, per-letter wave, sine text

Jitter

Small random offsets per frame, continuously. Reads as alarm or energy; loud, and it fights reading.

also: shake, vibrate, nervous text

Rubber band

Text scaling past its size on one axis and settling, borrowed from character animation. A little reads as life; a lot reads as cartoon.

also: elastic, squash and stretch, bounce scale

see

Split-flap

Characters flipping over on a horizontal axis like a departure board, or rolling vertically like an odometer, cycling until they land on the target glyph.

also: flip board, rolodex, departure board

see

Text morph

One word becoming another, by cross-fading character by character or by interpolating glyph outlines. Cross-fade is cheap; outline morph needs matching shapes.

also: word to word, character cross-fade, shape morph

see

Text on a path

Letters set along a curve or circle (SVG textPath). Can rotate slowly; keep the arc gentle enough to read.

also: circular text, curved type, textPath

Vertical text

Text running top to bottom (writing-mode vertical) or rotated 90 degrees. Spine-style labels for margins and edges.

also: writing-mode, sideways text, rotated label

Fit text

A headline sized so it fills its container exactly on one line, via clamp() or measure-and-scale. Size follows width, not a fixed scale step.

also: fluid headline, viewport-fit, fills the width

see

Blend-mode text

Text whose color is computed against what is behind it: difference inverts over anything, multiply darkens. Guarantees legibility over mixed backgrounds.

also: difference, mix-blend-mode, inverting text

Video-masked text

Video visible only through the letterforms: an image fill that moves. Heavy; one instance per page.

also: video in the letters, text as mask, moving fill

see

Stagger order

The order the pieces arrive in: left to right, from the middle out, from both ends, random. Same motion, different feel: linear reads as reading, center-out reads as bloom.

also: from the center, from the ends, random order

see

Cursor-reactive text

Letters that respond to pointer distance: weight, position, or scale changing within a radius. Needs a static fallback for touch.

also: magnetic, follows the mouse, proximity effect

see

Loading dots

Three dots pulsing in sequence to show waiting. The text equivalent of a spinner; never on anything that takes under half a second.

also: typing indicator, three dots, ellipsis pulse

see

Underline style

The underline’s thickness, offset, color and style, each set independently of the text. The browser default (thin, tight, same color) is almost never the right one.

also: text-decoration, offset underline, thick underline

see

Breathe

A slow repeated scale or weight pulse on a label, a few percent, to draw the eye without demanding it. The text cousin of ambient motion.

also: attention pulse, gentle pulse, idle emphasis

see

Shimmer

A light band passing across the text or a placeholder, the loading-skeleton motion applied to type. Reads as waiting or as gloss; rarely as neither.

also: shine sweep, skeleton shimmer, light band

Muddy

Bugs

Naming what is wrong precisely: the shape of a report, the kinds of failure, where they come from, and what to do about them.

Bug report

One message with five parts: what you saw, what you expected, where (page, entry, viewport width, browser), since when (the last change that touched it), how often. Paste the console line if there is one. Anything less starts a guessing game.

also: report, write-up, ticket

Expected vs actual

The two halves of any report. Expected is the behaviour you meant; actual is what happened. Stating both turns an opinion into a testable claim.

also: expected, actual, should

Repro

The shortest numbered sequence that makes the bug appear from a fresh load. If it cannot be reproduced it cannot be confirmed fixed.

also: steps to reproduce, reproducible, recipe

Intermittent

A failure that happens only some of the time. Almost always timing (a race), a cache, or a variable nobody is watching: viewport width, scroll speed, a font arriving late.

also: flaky, sometimes, random

Regression

Something that worked before a change and fails after it. Name the last good version or the change that preceded it; that halves the search.

also: it used to work, broke after, worked before

Edge case

A failure at an extreme or unusual input: empty, exactly one, very long, the last item, zero width. The main path works; the boundary does not.

also: boundary, only when, corner case

Environment

Where the bug is seen: browser and version, device, viewport width, OS, network. Many bugs live in one environment only; a report without it may be unreproducible everywhere else.

also: browser, device, viewport

Console error

A message in the browser console naming the failing line. The single most useful thing to paste: it says what threw, where, and in what order.

also: red error, stack trace, dev tools

404 / missing asset

The path points at nothing: wrong folder, wrong extension (a .png referenced as .jpg), a case mismatch that works locally and fails live, a moved file. The console lists the URL that failed.

also: dead link, broken image, file not found

Blank page

Nothing rendered. Usually a script that threw before drawing, a CSS rule hiding everything while it waits on something, or a file served with the wrong type. Console first, then view source.

also: white screen, nothing renders, empty page

Layout shift

Content moving after it first appears: images without reserved dimensions, fonts swapping in at a different size, late-injected elements. Reserve the space and it stops.

also: CLS, jumps, content moves after load

Overflow / cut off

Content larger than its box: clipped (hidden), spilling (visible past the edge), or forcing a horizontal scrollbar. A fixed width or a long unbreakable string is the usual cause.

also: clipped, text cut off, spills out

Misalignment

Edges or baselines that should share a line and do not. The smoking gun is a near-miss number: 21 next to 20.9. Report which two edges and by how much.

also: off by a pixel, not lined up, drifts

Stacking bug

An element drawn under another because of z-index or a stacking context it did not expect to be in. Report which element is under which.

also: behind, underneath, hidden behind the header

see

Dead control

A control that does not respond: covered by an invisible layer, pointer-events none, a handler never attached, or a disabled state that stuck. Say whether the cursor changes over it.

also: can’t click, nothing happens, unclickable

Double fire

A handler bound twice, or an event bubbling to two listeners, so one action runs two times. Symptom: counters jump by two, two toasts, two requests.

also: fires twice, runs twice, duplicate

Stuck state

A state that should clear and does not: hover that lingers on touch, a class never removed, a timer cleared early, a flag not reset on navigation.

also: doesn’t reset, stays highlighted, hover stuck

Race condition

Two things that assume an order the browser does not guarantee: measuring before fonts load, observing before render, reading a value the fetch has not returned. The classic source of intermittent bugs.

also: timing, depends on order, loads too early

see

Stale cache

The browser or CDN serving the previous file. Hard refresh, cache-bust the URL, or wait for the deploy; only then call it a bug.

also: old version, not showing my change, cached

see

Partial deploy

The live site mid-update: HTML live before its images and CSS. GitHub Pages is not atomic, so the first minutes after a push can show broken assets that heal by themselves.

also: deploy lag, live but old, some files updated

see

Works locally

A difference between environments: file case (Mac ignores it, the server does not), a file never committed, a font only installed locally, an absolute path to this machine.

also: fine on my machine, broken live, only in production

Jank

Dropped frames during scroll or animation. Something is animating layout (top, height, width) or doing work on every scroll event. Report where and on which device.

also: stutter, choppy, drops frames

see ,

Hang

The main thread blocked: a loop that never ends, a huge synchronous task, a layout thrash. The page cannot even paint. Say what you did last.

also: freeze, infinite loop, locked up

Memory leak

Objects kept alive after their use: observers never disconnected, timers never cleared, listeners added on every replay. The page is fine at first and degrades.

also: gets slower over time, tab grows, leaks

Flash of fallback

The page rendering before its CSS or fonts arrive, then swapping. A short flash is normal; a jump in size means the fallback is unmatched.

also: FOUT, flicker on load, font swaps

see

Wrong font rendering

The requested face or weight is not loading, so the browser substitutes or synthesizes. A faux bold is the tell: smeared, too dark. Check the font request and the weights it actually includes.

also: fallback showing, faux bold, wrong weight

Squashed / blurry image

Aspect or resolution problems: width and height both forced (distortion), a 1x asset on a 2x screen (blur), an upscaled thumbnail (pixels).

also: stretched, distorted, pixelated

see ,

Wrong value

A value that is not the token or the spec: a hard-coded hex, a stray opacity, a size one step off the scale. Name the value you see and the value you expect.

also: wrong shade, not the token, hard-coded

see ,

Off by one

A count or index wrong by exactly one: the last item dropped, numbering from zero, a loop that stops early. Give the expected and actual numbers.

also: one too many, missing the last one, starts at zero

Responsive break

Layout rules applied at the wrong width: a min-width where max-width was meant, a fixed width inside a fluid column, a breakpoint that fires late. Give the exact width where it breaks.

also: wrong breakpoint, squished at tablet, mobile layout on desktop

see

Scroll problem

Scrolling that jumps, locks, or lands wrong: a modal that never restored body scroll, an anchor with no offset under a sticky header, a smooth-scroll library fighting the browser.

also: scroll jumps, can’t scroll, scroll lock stuck

see

Keyboard trap

Keyboard focus that cannot leave a region, or vanishes after an action. Esc should close, and focus should return to where it came from.

also: focus trap, can’t tab out, focus lost

see ,

Not a bug

The report describes the designed behaviour. Say what you expected instead and it becomes a change request, which is a different conversation.

also: by design, working as intended, expected behaviour

Root cause

The single condition that produces the symptom. A fix for the symptom without the cause returns as a regression. Inspect actual state before proposing anything; no checklist guesses.

also: the real reason, underlying cause, why it happens

Severity

How bad (severity) against how soon (priority). Blocker: nothing works. Critical: the main path is broken. Minor: wrong but usable. Cosmetic: looks off. Say which, so fixes are ordered.

also: blocker, critical, minor

Revert or fix forward

Two responses to a live bug: restore the last good version, or fix in place. Revert when it is live and the cause is unknown; fix forward when the cause is known and small.

also: roll back, patch, hotfix

see

Bisect

Finding the change that introduced a bug by comparing versions, or halving the range of commits until one is left. Needs a last-known-good version to start from.

also: what changed, narrow it down, which commit

see

Typo

Wrong text. Still a bug; report the exact string and where it appears so it can be searched for.

also: wrong word, misspelled, copy error

Wrong target

A fix that landed on more or different elements than intended: a selector too broad, a regex too greedy, a class shared by things that should not share it. Say which elements changed and which should have.

also: changed the wrong thing, applied everywhere, selector too broad

A commit is a saved state with a message; a branch is a line of commits apart from main; a diff is the change between two states.

Endpoint / JSON

Daemon / registry

Semantic HTML

also: a11y, accessibility, ARIA

Focus order

Meta

Font loading

Hard-coded

Audio

Words for plug-in and DAW work: formats, hosts, signal, time, control, and the interface conventions instruments use.

Plug-in

A module the host loads to process or generate audio. An effect takes audio in; an instrument takes MIDI in and makes audio. A standalone build wraps the same code as its own application.

also: plugin, effect, instrument

Format

The contract between plug-in and host. VST3 (Steinberg) loads in most hosts; AU (Apple) is required by Logic and GarageBand; AAX is Pro Tools; CLAP is the open newcomer. One codebase builds all of them.

also: VST3, AU, Audio Unit

Host / DAW

The application that loads plug-ins, sends them audio and MIDI, and records the result: Ableton Live, Logic, Maschine. The host owns tempo, transport, and the session file.

also: DAW, host, sequencer

Insert / send / bus

An insert places an effect directly in one track’s signal path; a send copies part of a track to a return bus, where a shared effect lives. A bus is any summed path.

also: insert, send, return

Signal chain

The order audio passes through processors. Order changes the result: a compressor before reverb is not the same as reverb before a compressor.

also: signal flow, routing, path

Dry / wet

Dry is the unprocessed input; wet is the processed output. A mix control blends the two. A parallel path keeps the dry signal untouched underneath.

also: mix, blend, dry

Parameter

A named value the host can see, automate and save: a knob, a switch, a menu. Everything the user turns should be a parameter with a range, a default and a display unit.

also: param, control value, exposed control

Automation

The host recording and replaying parameter changes over time. It needs the parameter exposed and smoothed, and it records a gesture as well as a value.

also: automation lane, write, read

Modulation

A parameter driven from inside the plug-in by a source: an LFO, an envelope, a step sequencer. Modulation moves on its own; automation is drawn in the host.

also: mod, mod source, mod matrix

LFO

A slow repeating shape used as a modulation source: sine, triangle, square, random. Usually synced to tempo so its cycle is a note length.

also: low frequency oscillator, wobble

Envelope

The shape of a value over time. ADSR: attack (rise), decay (fall to the sustain level), sustain (hold while the note lasts), release (fall after note-off). An envelope follower traces the loudness of a signal.

also: ADSR, attack, decay

Gate

Two meanings. In a repeat effect, the fraction of each interval the slice sounds (a short gate is choppy). In dynamics, a gate silences the signal below a threshold.

also: gate length, noise gate, threshold

Sample rate / buffer size

Sample rate is how many samples per second describe the audio (44.1k, 48k, 96k). Buffer size is how many samples the host hands the plug-in per call. Small buffers mean low latency and more CPU.

also: sample rate, buffer size, block size

Latency / lookahead

The delay a plug-in adds. A process that needs to see ahead (lookahead) reports its latency so the host shifts everything else to compensate.

also: latency, lookahead, delay compensation

Tempo sync / transport

Reading the host’s tempo and playhead so time values are in beats and the plug-in knows where it is. Position is counted in ppq (pulses per quarter). When stopped, a plug-in can free-run at the last known BPM.

also: BPM, host sync, playhead

Note division

A duration as a fraction of a bar: 1/4, 1/16, 1/64. Dotted is one and a half times the length; triplet is two thirds. A rate ladder steps through the divisions in order.

also: rate, division, 1/16

MIDI

Note and control messages: which note, how hard (velocity), when it starts and stops, plus continuous controllers (CC). Instruments consume it; effects can listen to it for triggers.

also: notes, CC, velocity

Gain / level / dB

Gain is the amount of amplification; level is the resulting loudness, measured in dB. 0 dBFS is the digital ceiling; anything above clips. Headroom is the space left below it.

also: gain, level, volume

Meter

A display of level. Peak shows the instant maximum; RMS or VU shows the average; LUFS shows perceived loudness. A clip indicator latches when the signal goes over.

also: VU, peak meter, RMS

Waveform / scope

A drawing of amplitude over time. A scope shows the live signal as it passes; a waveform view shows a stored buffer, usually as peak columns.

also: waveform view, oscilloscope, scope

Spectrum / spectrogram

Amplitude by frequency at one moment (spectrum) or over time (spectrogram). What an EQ or analyzer displays.

also: analyzer, FFT, EQ display

Filter

Removes frequencies above (low-pass), below (high-pass) or outside (band-pass) a cutoff. Resonance boosts at the cutoff. Slope is in dB per octave: 12 is gentle, 24 is steep.

also: low-pass, high-pass, band-pass

Buffer / slice / grain

A buffer is stored audio; a slice is a region of it played back; a grain is a very short slice with a fade at each end. Beat repeat works on slices; granular synthesis works on grains.

also: buffer, slice, grain

Scrub / scan

Moving the read position through a buffer by hand. Every grid tick fires a slice from wherever the cursor is; the gesture is the instrument.

also: scrub, scan, read head

Retrigger / beat repeat

Capturing a slice of incoming audio and firing it again on every tick of a note division. Ableton’s Beat Repeat is the reference. A retrigger starts the slice from its beginning.

also: beat repeat, stutter, retrigger

Voice

One playing instance of a sound. Two alternating voices let a new slice start while the last one fades out. Polyphony is the voice count; stealing is which voice gets cut when they run out.

also: voices, polyphony, mono

Declick / smoothing

Audible steps when a value or a slice boundary jumps. Fixed by ramping parameters over a few milliseconds and fading slice edges. Zipper noise is the unsmoothed version.

also: declick, crossfade, zipper

Oversampling / aliasing

Running a stage at a multiple of the sample rate so nonlinear processes (saturation, distortion) do not fold high frequencies back down as aliasing. Costs CPU; apply it only where needed.

also: oversampling, aliasing, 2x

Preset / state

The saved values of every parameter plus anything else needed to restore the sound, such as a sample path. The host stores state in the session; the plug-in offers presets for recall.

also: preset, patch, state

Editor / processor

The plug-in’s window is the editor: the view. The processor is the audio engine. The editor can close while audio keeps running, and it must not touch the audio thread directly.

also: GUI, UI, editor

Knob / fader / switch

A knob turns through a range; a fader slides; a switch flips between states. Knobs take a vertical drag by convention; double-click resets to default; a modifier drag is fine.

also: knob, rotary, fader

Bypass

Passing audio through untouched. The host has its own bypass outside the plug-in; an internal bypass can be ramped to avoid clicks. Not the same as dry/wet at zero.

also: bypass, enable, on/off

Sidechain

A second input the plug-in listens to, usually to trigger or control the main signal without being heard itself.

also: sidechain, external input, key input

Stereo / mono / mid-side

Channel layouts. Mid is what left and right share; side is their difference. A width control scales the side. Mono compatibility means the mix survives the sides being cancelled.

also: stereo, mono, mid-side

Audio thread

The audio callback must never wait: no memory allocation, no locks, no file access. The UI and the engine exchange data through lock-free queues and atomics, and buffers are preallocated.

also: real-time safety, audio callback, lock-free

CPU load

How much of the available processing time the plug-in consumes per block. Measured at a stated sample rate and buffer size; oversampling and lookahead raise it.

also: DSP load, performance, CPU meter

Capture / take / bounce

Recording the plug-in’s output to a file (a take), or rendering a track in place (bounce or freeze). A grab captures the incoming signal into the plug-in’s own buffer instead.

also: record, take, bounce

Ring buffer

A fixed-length buffer that overwrites its oldest samples, so it always holds the last N seconds of input. The basis of any “grab what just played” feature.

also: rolling buffer, circular buffer, ring

Validation

Host-side checks a plug-in must pass before it loads: auval for Audio Units, pluginval for general behaviour. A failed validation means the host hides the plug-in.

also: auval, pluginval, host scan

Demo / license

How a commercial plug-in limits use before purchase (a time limit, periodic silence, no saving) and unlocks after. iLok is a hardware or cloud license system; a key file or serial is the lighter option.

also: trial, license key, activation
